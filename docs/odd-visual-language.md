# ODD visual language

ODD uses quiet OpenStation-native chrome around expressive app content.

- Icons are simple, single-color silhouettes or line symbols that remain clear
  at small sizes. Avoid multicolor emoji-like controls.
- Controls use text plus an icon when the action is not universally obvious.
- App windows open at a bounded useful size and remain resizable unless the app
  has a strong reason not to be.
- Every loading, empty, success, partial-failure, and hard-failure state is
  visible and actionable.
- Reduced motion, keyboard access, high contrast, touch targets, and narrow
  windows are first-class states.
- ODD does not restyle OpenStation's dock, desktop, system icons, or window
  manager. It uses the host's public extension points.
